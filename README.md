# 圖片拼接工具（手動裁切版）

純前端、零後端的截圖拼接工具。上傳多張截圖，逐張框選要保留的區域、調整順序後，垂直拼接成一張長圖。手機觸控為第一優先。

## 特色
- **本機處理、圖片不上傳**：所有運算在瀏覽器端完成（FileReader + Canvas），從架構上消除資料外洩風險
- **手機觸控完整支援**：拖拽紅色裁切框、8 向控制點縮放
- **檔名自然排序**：`1, 2, …, 10` 正確排序，畫面順序即拼接順序（位置 1 在最上方）
- **多種輸出尺寸**：原始大小／2x／3x／固定寬度 3000px
- **單一 HTML 檔**：無相依套件、無建置工具、離線可用

## 使用方式
1. 用瀏覽器開啟 `index.html`（或部署後的網址）
2. 選擇多張圖片
3. 拖拽紅色裁切框選取每張圖要保留的區域，控制點可 8 向縮放
4. 需要時用下拉選單調整拼接順序（既有裁切框會保留）
5. 點「開始拼接」，垂直合併成長圖

## 資安設計
- **本機處理原則**：無後端、無上傳，是本工具最大資安優勢
- **檔名 XSS 防護**：檔名經 `escapeHtml()` 轉義後才插入 DOM，惡意檔名不會執行
- **CSP 標頭**：`<head>` 內嵌 Content-Security-Policy，限制 script/style 來源並禁止一切外部連線（`connect-src 'none'`）
- **記憶體上限保護**：上傳時檢查張數與總像素，超過上限以畫面內提示友善阻擋，避免手機記憶體被撐爆
- **無殘留**：不寫入 localStorage，重整即清空

## 技術
Vanilla JS + Canvas API，無相依套件、無建置工具。單檔零建置。
